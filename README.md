
# Fake Job Detection

## About the Project
This project aims to develop a system to identify potentially fraudulent job postings using machine learning.

## Objectives
- Collect publicly available job posting data from permitted sources.
- Clean and organize job posting information.
- Prepare a dataset for fake job detection.
- Explore machine learning techniques for classification.

## Data Collection
Job data will be collected from sources that permit the intended use, using official APIs or permitted web scraping.

## Project Status
Currently working on data collection and dataset preparation.
